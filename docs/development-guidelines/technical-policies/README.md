# Technical Policies

> 作成日: 2026-11-18
> 更新日: 2026-11-23
> 作成者: Codex

複数のプロジェクトに適用する技術・開発上の共通方針を置きます。品質、開発プロセス、レビュー工程、ブランチ戦略、品質ゲート、AI 協働、AGENTS.md の作成、リポジトリの公開・非公開などの方針と、再利用できるテンプレートや記入例を管理します。Windows のローカルアプリケーションデータを扱うリファレンスは `windows-local-app-data/` に置きます。テンプレートと記入例は `templates/` に置きます。

方針の種類を追加・変更した場合は、この README と親フォルダの README を更新してください。
