# Technical Policies

> 作成日: 2026-11-18
> 更新日: 2026-11-24
> 作成者: Codex

複数のプロジェクトに適用する技術・開発上の共通方針を置きます。品質、開発プロセス、レビュー工程、ブランチ戦略、品質ゲート、AI 協働、AGENTS.md の作成、リポジトリの公開・非公開などの方針と、再利用できるテンプレートや記入例を管理します。[Issue Type・共通ラベル運用方針](https://github.com/Ateliers-Dev/.github/blob/main/docs/issue-classification-and-label-policy.md)は Ateliers-Dev/.github を正本とし、このサイトから参照します。継続的改善の共通枠組みは[継続的改善ガイドライン](./continuous-improvement-guidelines.md)に記載します。Windows のローカルアプリケーションデータを扱うリファレンスは `windows-local-app-data/` に置きます。テンプレートと記入例は `templates/` に置きます。

方針の種類を追加・変更した場合は、この README と親フォルダの README を更新してください。
