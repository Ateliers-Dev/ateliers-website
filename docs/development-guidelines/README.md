# Development Guidelines

> 作成日: 2026-11-18
> 更新日: 2026-11-24
> 作成者: Codex

複数プロジェクトに共通する開発方針、ドキュメント指針、Ateliers の理念、ウェブサイト運営方針を置きます。技術・開発方針には、品質、開発プロセス、レビュー工程、ブランチ戦略、品質ゲート、AI 協働、AGENTS.md の作成、リポジトリの公開・非公開、Windows ローカルアプリケーションデータ管理などを扱う `technical-policies/` を設けています。

継続的改善の共通方針は `technical-policies/continuous-improvement-guidelines.md` に、再利用可能な改善事例は `continuous-improvement/` に置きます。今回の具体的な事例は文書作成と報告品質に限ります。

掲載する方針の種類や分類基準を追加・変更した場合は、この README と `docs/README.md` を更新してください。
